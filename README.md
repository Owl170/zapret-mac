# ZapretMac

Текущая версия: **0.2.4**.

[Скачать последний релиз](https://github.com/Owl170/zapret-mac/releases/latest) · [Инструкция по голосу Discord](VOICE.md) · [Проверки macOS](https://github.com/Owl170/zapret-mac/actions/workflows/macos-check.yml) · [Аудит кода](AUDIT.md)

Локальный TCP-обход DPI для macOS на основе официального `tpws` из проекта [bol-van/zapret](https://github.com/bol-van/zapret), с отдельным экспериментальным UDP-relay для голоса Discord. Списки доменов, IP, UDP-фейк и тестовые адреса взяты из [Flowseal 1.10.3](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.3). Это самостоятельный порт менеджера, а не официальный релиз Flowseal.

**Полного соответствия Windows-версии нет.** Её `winws` перехватывает TCP и UDP через WinDivert. macOS-движок `tpws` работает с TCP. В версии 0.2.0 добавлен независимый Python UDP-relay: PF redirection/NAT lookup, стабильные сессии, фейки при Discord discovery/STUN, самопроверка и счётчики. Полный путь IPv4 через PF проверен на macOS 14; реальный двусторонний голос в сети пользователя **не подтверждён**. UDP-игровые стратегии оригинала, QUIC-фейки, подмена TCP sequence и `badsum` не перенесены. Официальная [документация macOS](https://github.com/bol-van/zapret/blob/master/docs/bsd.en.md#macos) объясняет ограничения готового пакетного движка.

Пакет подготовлен для **macOS 12+**, Apple Silicon и Intel. При установке собирается универсальный бинарник из вложенных исходников; Homebrew, внешний сервер и виртуальная машина не нужны. Нужны Apple Command Line Tools и Python 3.9+ из этих инструментов. На GitHub-раннере macOS 14 успешно проверены 161 Python-тест, универсальная сборка, 100 конфигураций движка, 16 вариантов синтаксиса PF и ABI. Диагностика подтвердила полный UDP-путь IPv4; следующая IPv6-проба завершилась ошибкой маршрута и отключила только IPv6. Реальный обход DPI и звонок Discord в сети пользователя **не подтверждены**; UDP включается только после успешной локальной самопроверки. Подробности и ограничения — в [AUDIT.md](AUDIT.md).

## Установка и запуск

1. На Mac откройте [Releases](https://github.com/Owl170/zapret-mac/releases/latest), в разделе **Assets** скачайте архив `ZapretMac-<версия>.zip` и распакуйте его.
2. Откройте `install.command`. Если появится предложение установить Apple Command Line Tools, завершите их установку и повторите запуск. Установщик запросит пароль администратора.
3. Откройте `service.command` и выберите **1 — Включить / перезапустить**.
4. Проверьте YouTube и Discord. Если доступа нет, выберите **17 — Проверка всех TCP-стратегий**, затем **3 — Выбрать стратегию**. Проверки не выбирают профиль автоматически и восстанавливают прежние настройки.
5. Для запуска при загрузке Mac выберите **4 — Включить автозапуск**. Для отключения — **5**. **2** останавливает текущий запуск, но сохраняет установленный автозапуск на следующую загрузку.

Для голоса Discord откройте **`voice.command`** и выберите **1**. После сообщения о пройденной UDP-самопроверке переподключитесь к голосовому каналу. По умолчанию профиль `fake` отправляет шесть фейков с обычным TTL, как UDP-профиль Discord в Flowseal 1.10.3. Пункт **8** помогает проверить профили relay/fake/ttl3/ttl5/ttl7/ttl9; профиль сохраняется только после вашего подтверждения двустороннего звука. Подробная последовательность и разбор ошибок — в [VOICE.md](VOICE.md).

UDP IPv4 и IPv6 проверяются отдельно. Неудачная IPv6-проба отключает его UDP-правила и сохраняет проверенный IPv4. Если IPv4-проба не проходит или relay завершается, обычный UDP-перехват отключается.

Если Finder не запускает `.command`, откройте Terminal и выполните команды из распакованной папки:

```bash
cd "$HOME/Downloads/ZapretMac"
bash install.command
bash service.command
```

Путь исправьте, если архив распакован в другую папку. Глобально отключать Gatekeeper или SIP не требуется.

### Установка через Git

Откройте Terminal на Mac и выполните:

```bash
git clone https://github.com/Owl170/zapret-mac.git
cd zapret-mac
bash install.command
bash voice.command
```

В меню голоса выберите **1**, дождитесь результата UDP-самопроверки и переподключитесь к каналу Discord. Если `git` предложит установить Command Line Tools, завершите установку и повторите команды. Для отдельного TCP-меню запустите `bash service.command`.

### Обновление и удаление

Для установки новой версии скачайте новый архив из Releases и повторно запустите `install.command`. При установке через Git выполните из папки проекта:

```bash
git pull --ff-only
bash install.command
bash voice.command
```

Установщик сохраняет настройки и пользовательские списки. Для полного отключения движка и автозапуска откройте `uninstall.command`; сохранённые настройки и отчёты останутся в каталоге установки.

После включения или смены стратегии перезапустите браузер/Discord: уже установленные TCP-соединения не перенаправляются заново. Результат зависит от провайдера и текущего DPI. Успешный HTTP/TLS-тест не доказывает работоспособность видео или голоса.

## Функции

| Функция оригинала | В этом пакете |
| --- | --- |
| YouTube / Discord и дополнительные домены по TCP | `tpws`, включая приложение и браузеры при подходящей стратегии |
| Переключение стратегий | 7 собственных TCP-профилей плюс контрольный passthrough; ALT/FAKE Windows не выдаются за совместимые |
| Install / Remove Service | системный LaunchDaemon, старт/стоп, удаление автозапуска |
| Check Status | состояние supervisor и движка, активный и выбранный профили |
| Game Filter и изменение портов | TCP, например `1024-1934,1936-65535`; UDP отсутствует |
| IPSet none / loaded / any | область применения модификаций TCP; loaded учитывает пользовательские подсети |
| Доменные/IP-исключения | во всех TCP-профилях, включая Google и игровые порты; UDP использует только IP-исключения |
| Update IPSet / списков | проверка формата, резервная копия, откат при ошибке записи; пользовательские списки сохраняются |
| Update Hosts File | данные Flowseal в отдельном блоке `/etc/hosts`, резервная копия и удаление только своего блока |
| Check for Updates | проверка релиза Flowseal; автоматическая проверка при открытии меню, без установки Windows-бинарников |
| Run Diagnostics | PF, DNS, маршрут, системные прокси, IPv6, порт, движок и последние сообщения |
| Run Tests | адреса из исходного `targets.txt`, контрольный профиль и все TCP-стратегии, CSV-отчёт |
| DPI checkers оригинала | специализированные Windows-тесты не перенесены; доступны проверки TCP/TLS-ответов |
| Очистка кеша Discord | кеш перемещается в резервные папки; токены и настройки аккаунта сохраняются |
| Replace active fakes | смена набора фейков Windows не перенесена; UDP-relay использует включённый Discord-фейк |
| QUIC | опциональное блокирование UDP/443 для перехода поддерживающих fallback приложений на TCP |
| Голос Discord / UDP-фейки | экспериментальный отдельный relay, фейки при discovery/STUN с обычным или малым TTL, автоматическое снятие UDP-правил при неудаче самопроверки |
| UDP-игры | стратегии оригинала не перенесены |

**QUIC → TCP выключен по умолчанию.** Пункт 9 блокирует UDP/443 для всех обычных приложений, а не только YouTube. Приложения без TCP fallback могут перестать подключаться. Эта опция не обходит UDP-блокировки.

Для `IPSet any` изменяется TCP-трафик всех адресов на выбранных портах, кроме исключений. Для `none` отключаются профили IPSet и Game Filter; доменные профили продолжают работать. Game Filter с `loaded` охватывает только адреса из IPSet.

Списки hosts могут содержать временные адреса. Они применяются только при выборе пункта 11. Пункт 12 удаляет блок ZapretMac. Если ваши существующие записи конфликтуют с новыми доменами, применение прекращается и сообщает об этом.

## Пользовательские списки

Файлы находятся в `/Library/Application Support/ZapretMac/lists`:

- `list-general-user.txt`: дополнительные домены; поддомены учитываются автоматически.
- `list-exclude-user.txt`: исключённые домены; `^example.com` исключает только точное имя.
- `ipset-user.txt`: дополнительные IPv4/IPv6 или CIDR для режима loaded.
- `ipset-exclude-user.txt`: исключённые IPv4/IPv6 или CIDR.

По одному значению в строке, комментарии начинаются с `#`. Пункт 20 открывает папку. При необходимости редактируйте через Terminal:

```bash
sudo nano "/Library/Application Support/ZapretMac/lists/list-general-user.txt"
```

Затем выберите пункт 1 для перезапуска. Частные, loopback, link-local и multicast-адреса исключены из перехвата независимо от пользовательских файлов.

## DNS и совместимость

При блокировке DNS включите Secure DNS в браузере. Например, Chrome: «Использовать безопасный DNS» с выбранным поставщиком; Firefox: DNS через HTTPS, пользовательский URL `https://dns.google/dns-query`. Как и в оригинальном пакете, DNS настраивается отдельно. DNS браузера не меняет DNS приложения Discord.

VPN, Internet Sharing и нестандартные PF-правила могут мешать прозрачному режиму. Программа проверяет стандартные hooks `com.apple/*` и прекращает запуск при несовместимой активной конфигурации. Она не редактирует `/etc/pf.conf`. Если активные правила отсутствуют, загружается имеющийся системный `/etc/pf.conf`, затем правила добавляются только в `com.apple/zapret-macos` и `com.apple/zapret-macos-udp`.

Для доступа к `/dev/pf` `tpws` и UDP-relay работают от root. Запросы процессов root исключены из перехвата во избежание рекурсии. Сетевые тесты запускаются от пользователя установки. TCP-проверки используют HTTP/1.1. UDP-самопроверка обращается к зарезервированному адресу и проверяет полный путь перенаправления и обратного NAT внутри Mac. Установленный системный/браузерный HTTP-прокси может менять путь обычного трафика; TCP-тесты явно проверяют прямое соединение.

При остановке снимаются только собственные правила и собственный токен включения PF. Глобальный PF не выключается принудительно. При завершении `tpws` supervisor снимает перенаправления и повторяет запуск. Нормальное завершение supervisor тоже снимает правила; принудительное `kill -9` не позволяет выполнить cleanup. При следующем запуске очищаются собственные оставшиеся правила.

## Логи, удаление и команды

Логи: `/Library/Application Support/ZapretMac/logs/service.log` и `udp.log`. CSV TCP-тестов и JSON наблюдений за UDP сохраняются в той же папке. Они не содержат звук, токены или данные аккаунта. Резервные копии списков и hosts — в `backups`. Копии кеша Discord лежат рядом с соответствующей папкой кеша и имеют суффикс `.zapret-backup-*`.

`uninstall.command` останавливает обход, удаляет LaunchDaemon, бинарник и контроллер, а также удаляет свой блок hosts. Настройки, списки и резервные копии сохраняются в каталоге установки. Удаляйте их отдельно, когда они больше не нужны.

```bash
sudo /usr/bin/python3 "/Library/Application Support/ZapretMac/zapret.py" status
sudo /usr/bin/python3 "/Library/Application Support/ZapretMac/zapret.py" diagnostics
sudo /usr/bin/python3 "/Library/Application Support/ZapretMac/zapret.py" stop
```

## Проверка исходников

Контроллер использует только стандартную библиотеку Python. Исходники движка включены, их версия зафиксирована в `PROVENANCE.json`; в установщике нет загрузки исполняемого кода из сети.

```bash
python3 -m unittest discover -s tests -v
make -C engine/tpws mac CC=clang CFLAGS='-std=gnu99 -Os -ffunction-sections -fdata-sections' LDFLAGS=''
sudo python3 scripts/check_native.py engine/tpws/tpws
sudo python3 scripts/check_pf_udp.py
```

`check_native.py` проверяет 100 комбинаций стратегии/фильтров и 16 PF-конфигураций с `--dry-run`/`pfctl -n`, без применения правил. `check_pf_udp.py` требует остановить ZapretMac и применяет временные UDP-правила только для зарезервированных тестовых адресов; проверяет перехват, NAT lookup и обратный ответ, затем снимает правила и свой токен PF. При ошибке выводит диагностику собственных правил и служебного состояния PF. Эти проверки включены в [macOS CI](https://github.com/Owl170/zapret-mac/actions/workflows/macos-check.yml); точный результат смотрите для соответствующего коммита. После них для подтверждения обхода всё равно нужен реальный звонок на Mac в сети с соответствующими блокировками.

## Автоматические версии и релизы

Подключено расширение GitHub Actions [GitHub Tag Action](https://github.com/mathieudutour/github-tag-action). Workflow [Automatic version and release](.github/workflows/release.yml) запускается после каждого push в `main`:

1. Выполняет тесты Python.
2. Рассчитывает следующую версию по сообщениям коммитов: `fix: ...` повышает patch, `feat: ...` — minor, `feat!: ...` или `BREAKING CHANGE:` — major. Для остальных изменений по умолчанию повышается patch.
3. Обновляет `VERSION`, строки текущей версии в README и VOICE.md, а также версию и контрольные суммы в `PROVENANCE.json`.
4. Собирает и проверяет ZIP, затем сохраняет изменения коммитом бота, создаёт тег `vX.Y.Z` на этом коммите и публикует GitHub Release с ZIP и SHA256.

Установленная программа читает номер из `VERSION`; вручную менять номер в Python-коде не требуется. Первоначальный тег `v0.2.0` публикуется без дополнительного повышения версии. Повтор после прерывания публикации продолжает согласованный коммит версии без нового повышения номера. Повторный запуск того же отмеченного тегом коммита обновляет его архив, сохраняя номер. Теги существующих версий не перемещаются.

Workflow использует встроенный `GITHUB_TOKEN` с правом `contents: write`. Дополнительные токены или платная подписка на расширение не требуются. Для ветки `main` с запретом прямой записи бота потребуется адаптация workflow под правила репозитория. Результат можно проверить на вкладке [Actions](https://github.com/Owl170/zapret-mac/actions).
